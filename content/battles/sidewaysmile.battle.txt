# The Sideways Mile - the order of 25 August 2026, tick 1063.
#
# Not a designed scenario. This is an arrangement that happened in play,
# recorded, and kept because the route it produced was wrong: a spearman
# regiment held eighty-one degrees against a march on minus nine for four
# hundred metres, arrived ninety degrees off the front it was given, and
# averaged 0,6 m/s of the 1,0 the ground allowed. See M81.
#
# The rule it exists to serve (W8): a bug that was real gets a fixture built
# from the recording, red on the code that produced it, and it joins the bench
# so that the cost of the route is swept and not merely passed or failed.
#
# Everything here is read off the `Scene` block the recording writes on every
# order - position, facing and footprint per regiment. The map, the seed and
# the orders of battle are greatfield's, because that is what was being
# played; what differs is that these regiments have already moved, so this is
# a mid-battle pose rather than a deployment. Three regiments are away from
# the start line and facing oddly, which is the whole point: M79 found that an
# order given from a pose the last order left behind is the case no ceiling
# was pricing.
#
# POSITIONS ARE SNAPPED TO CELL CENTRES, AND ROWS RUN NORTH TO SOUTH. The
# reader takes authored map cells and row zero is the top of the drawn map, so
# world y is 2387,5 - row * 25 and not row * 25 + 12,5. Snapping then moves the
# recording's metre positions by up to half a cell - U5 goes from y 1776,4 to
# 1787,5, eleven metres north, which puts it nearer the Horse Archers that
# refused its line rather than further from them. The fault is
# reproduced at this pose, and the exact-metre version of it lives in
# TheSidewaysMileTests, which is the gate. This file is the bench entry.
#
# The mover is the spearman regiment at 12,71 facing 144,4 - the only one off
# the column - and where it was sent is in TheSidewaysMileTests.
